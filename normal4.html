🐍 Python编程入门教程

什么是Python？

Python是一种高级编程语言，以其简洁易读的语法而闻名。它广泛应用于Web开发、数据分析、人工智能、科学计算等领域。

💡 为什么选择Python？
  • 语法简单，易于学习
  • 丰富的库和框架
  • 跨平台兼容
  • 社区活跃，资源丰富

第一个Python程序

让我们从经典的"Hello World"程序开始：

print("Hello, World!")

变量和数据类型

Python支持多种数据类型，包括整数、浮点数、字符串、列表等：

# 整数 age = 25 # 浮点数 price = 99.99 # 字符串 name = "Python" # 列表 fruits = ["苹果", "香蕉", "橙子"] print(f"名称：{name}，版本：3.11")

条件语句

使用if-elif-else进行条件判断：

score = 85 if score >= 90: print("优秀") elif score >= 80: print("良好") elif score >= 60: print("及格") else: print("不及格")

学习建议

编程学习需要持续练习，建议每天至少练习1-2小时。多做项目，多阅读优秀代码，参与开源社区，不断提升编程能力。
